ABU FATIMA CAR ACCESSORIES — WEBSITE PACKAGE

Files:
- index.html  Main responsive website
- style.css   Complete responsive styling
- script.js   Mobile menu, Arabic/English switch, WhatsApp quote form

How to use:
1. Upload these files to the root of your hosting/repository.
2. Make sure index.html is the published entry page.
3. Replace the placeholder WhatsApp links with the shop's real WhatsApp number.
4. Add your real shop phone/address/hours if desired.
5. For GitHub Pages, enable Pages from the repository's main branch/root folder.

Note:
This package was built as a complete standalone site because the uploaded ZIP contained only style.css; the original HTML/JS/assets were not included.
